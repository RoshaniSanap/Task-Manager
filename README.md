Task Manager Web Application

About the Project
Task Manager is a web-based application that helps users manage their daily tasks efficiently.

Features
- User Registration and Login
- Secure User Authentication
- Add New Tasks
- Edit and Delete Tasks
- Set Task Deadlines
- View Pending and Completed Tasks
- User-specific Task Management

Technologies Used
- HTML
- CSS
- JavaScript (Node.js)
- Express.js
- EJS (Embedded JavaScript)
- MySQL

Installation and Setup
1. Clone the repository.
2. Open the project folder.
3. Install dependencies:
npm install
4. Create a ".env" file and configure your database credentials.
5. Start the application:
node server.js
6. Open your browser and visit:
"http://localhost:8080"

Security
Environment variables are stored in ".env", which is excluded from GitHub using ".gitignore".
